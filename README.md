# 飯田経営パートナーズ

工務店・リフォーム会社向け経営コンサルティングサイトです。

## 構成

- `index.html`: トップページ
- `privacy.html`: プライバシーポリシー
- `styles.css`: スタイル
- `script.js`: モバイルメニューなどの動作
- `assets/`: 圧縮済み画像

## 公開

GitHub Pages の `main` ブランチから配信します。

検索結果へ掲載しない方針のため、各ページの `noindex` と `robots.txt` を設定しています。

## フォーム

受信メールアドレスと送信サービスを設定するまでは送信ボタンを無効化し、未送信を送信済みに見せない仕様です。
